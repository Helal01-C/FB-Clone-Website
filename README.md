# FB-Clone-Website

This is a Facebook clone website that I created during my free time to practice and improve my web development skills.

The project is inspired by the basic design and layout of Facebook. I built it to get hands-on experience with creating a social media interface, working with different web components, and improving my frontend development skills.

## Features

* Facebook-inspired user interface
* Responsive design
* Navigation bar
* User profile section
* Post and feed section
* Like and comment functionality
* Clean and simple layout

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

This project is mainly for learning and practice. It helped me improve my understanding of frontend development, page structure, responsive design, and JavaScript.

## Future Updates

I plan to add more features and improve the design and functionality of the website in the future.
